# Amiga 3D Prints

Printable mounting parts and editable designs for Amiga projects.

## Projects

- [Amiga Zorro LAN IDE CP Ethernet bezel spacers](zorro-lan-ide-cp/ethernet-bezel-spacers/): paired mounting blocks in 12–16 mm heights, with captive M3 nuts and adjustable bezel fixings.

- [Amiga A4000 SD35VC0 expansion bay bracket](sd35vc0-expansion-bay-bracket/): SD-to-IDE adaptor tray with a square front face, honeycomb base and recessed M3 nuts.
